# Accretion Power content handoff

Prepared October 28, 2026 from the existing repository working tree. This package contains content and original asset bytes only; it does not contain website implementation or a proposed design.

“This folder contains Accretion Power content and assets only. It does not specify website design. Use its business information, copy, photos, and logos within the destination template’s existing design. Preserve the destination template’s colors, fonts, layout, structure, spacing, responsive behavior, and scrolling/animations. Do not recreate the old Accretion Power website’s appearance.”

## Contents

- `company-information.md`: factual business topics with repository source references and qualifications.
- `website-copy.md`: existing substantive wording, product options, FAQs, displayed technical tables, and expressly labeled draft policies.
- `contact-and-links.md`: published contact details, website destinations, PDF references, and image credit links.
- `content-inventory.md`: source coverage, active asset accounting, and exclusions.
- `asset-manifest.json`: each exported file’s source, existing alt/caption, business subject, usage, dimensions, uncertainty, and SHA-256 checksum.
- `missing-or-uncertain.md`: missing facts, conflicts, fictional content, asset qualifications, and unresolved questions.
- `photos/`: 10 unique active photo/category-image assets, including an explicitly identified existing AI category illustration.
- `logos/`: 3 available AP monogram raster files: original supplied PNG, app-icon PNG, and multi-size favicon ICO.

Read missing-or-uncertain.md before reusing claims, draft policies, or imagery. Filenames under photos/ and logos/ are relative to this folder. Historical source paths elsewhere in these documents are traceability references, not dependencies needed to use the copied content. PDF destinations are references only; the source PDFs and homepage video are not bundled.

Assets were copied without modification and verified against their source checksums. Every active local image reference is accounted for in the inventory, including the intentionally excluded fictional portrait and technical drawing. There are no active remote photo requests or photographic CSS background URLs in the inspected source. No credentials, customer records, prices, source code, stylesheets, fonts, configuration, or screenshots are included.
